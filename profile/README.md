# 🐛 Troubleshooting

## Ronix doesn't open

Try the following:

- Make sure you're using Windows.
- Extract the `.zip` completely.
- Do not run Ronix directly from inside the archive.
- Restart Windows.
- Download the archive again if the file may have been corrupted.

---

## Ronix opens but doesn't work correctly

Try:

1. Close Ronix.
2. Close Roblox.
3. Restart both applications.
4. Check for a newer Ronix release.
5. Try a fresh extraction.

---

## The interface is frozen

Give the application a moment first.

If nothing changes:

1. Close Ronix.
2. Open Task Manager.
3. Make sure Ronix has completely closed.
4. Start it again.

---

## A script doesn't work

The problem may be the script rather than Ronix.

Try another known-good script.

If only one script fails while others work, the script itself may be outdated or incompatible.
